## 🌟 6 Chế Độ Người Dùng (User Modes)

1. **Creator Mode (Mode A):** Quản trị hồ sơ sáng tạo, Content Studio, Gói dịch vụ (Productized Services), Brand Deals, Tích hợp TikTok Display API.
2. **Freelancer Mode (Mode B):** Nhận diện cơ hội việc làm, Nộp đề xuất (Proposals), Thực thi hợp đồng Milestone và Escrow.
3. **Starter / Worker Mode (Mode C):** Thực thi tác vụ chuẩn hóa, Học tập và Đánh giá kỹ năng nhận chứng chỉ số (Learning-to-Earning).
4. **Business / Brand Mode (Mode D):** Bóc tách dự án bằng AI Scoping, Tuyển dụng Talent chất lượng cao, Ký quỹ an toàn tuyệt đối.
5. **Agency Hub (Mode E):** Quản lý nhiều thương hiệu cùng lúc, Điều phối Talent Roster, Báo cáo ROI.
6. **AI Operator (Mode F):** Quản lý chuỗi AI Agents, Tự động hóa tiếp nhận khách và xử lý quy trình.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Dự Án

### Yêu Cầu Môi Trường
- Node.js >= 18.0.0 (Khuyên dùng v20 hoặc v24)
- npm >= 9.0.0

### Khởi Chạy Local Dev Server
```bash
# Cài đặt dependencies (đã cài đặt)
npm install

# Khởi chạy máy chủ phát triển
npm run dev

# Mở trình duyệt tại: http://localhost:3000
```

### Lệnh Build Sản Phẩm
```bash
npm run build
```
